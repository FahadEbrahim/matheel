# Repository review, 7 September 2026

## Baseline and scope

The local checkout matched GitHub `main` at `1106c5481c6f6ebc2522d2869601f42a0c6636fb`. The latest published release was [v0.6.0](https://github.com/FahadEbrahim/matheel/releases/tag/v0.6.0), published 23 August 2026. GitHub was fetched before review. There were no open PRs and one open issue, [the existing detector-adapter investigation #46](https://github.com/FahadEbrahim/matheel/issues/46).

The review combined source inspection, the full default test suite, focused reproductions, real-model checks, and research into benchmark protocols and integrations. It covered dataset loading/writing/merging, archive/path handling, evaluation and resampling, leaderboard aggregation, caching/provenance, custom algorithms, model loading/vector scoring, CLI/UI workflows, dependencies, and CI/release configuration. CLI, Gradio, preprocessing and code-metric coverage relies substantially on the existing tests and targeted source inspection; this is not a claim that every code path or arbitrary input was exhaustively verified.

The user requested GitHub issues and PRs for bugs, while holding feature implementation and release planning until a coherent direction is agreed. No PR was merged, release tag created, package published, or external detector service used during this review.

## Confirmed findings and fixes

| Finding | Reproduction / effect | Issue | Fix PR |
| --- | --- | --- | --- |
| Dataset writes happen before output-path validation | A pre-existing output symlink is followed, an outside file is overwritten, then validation raises. Generated suffix/ID combinations can also collide and silently replace samples. | [#269](https://github.com/FahadEbrahim/matheel/issues/269) | [#272](https://github.com/FahadEbrahim/matheel/pull/272): preflight destinations, reject symlinks/unsafe suffixes and colliding paths |
| Cache reload changes identifiers | `001` becomes numeric; `NA`/`NULL` become missing. Cache hits can identify different files from misses. | [#270](https://github.com/FahadEbrahim/matheel/issues/270) | [#273](https://github.com/FahadEbrahim/matheel/pull/273): text-safe legacy loading and recorded dtypes for new caches |

Sentence-transformers 6.0.1 was the current stable release verified on [PyPI](https://pypi.org/project/sentence-transformers/) and the [upstream release page](https://github.com/huggingface/sentence-transformers/releases/tag/v6.0.1). Do not interpret the passing local model tests as proof that the whole pre-existing environment is dependency-consistent. The PR CI jobs install clean environments and include dependency-floor validation.

## Benchmark design findings

See the [release vision](next_release_vision.md) for the detailed proposed replacement workflow, categorized dataset candidates, external-tool adapter contracts, and synthetic-clone options. The most consequential gaps are benchmark protocol/version identity, model-role/pooling fidelity, prediction retention, full-corpus scaling, group-disjoint evaluation, and distinguishing clone/plagiarism/functional labels.

The current six dataset presets are SOCO14, IRPlag, ConPlag, IPCA, Student Code Similarity and Criminal Minds. New dataset/tool recommendations are research findings, not tested adapters or reproduced benchmark results. No external corpus was downloaded and no detector leaderboard score was generated in this review.

The proposed release remains on hold pending agreement on scope and completion of its acceptance gates. The bug-fix PRs are independently reviewable and do not imply approval of the new feature proposal.
